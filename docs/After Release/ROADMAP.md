# Project Roadmap

## Phase 1: Performance Optimization
- Migrate database backend from SQLite to PostgreSQL.
- Add connection pooling for database connections.
- Optimize canvas rendering of the interactive home page social circle.

## Phase 2: Community & Scale
- Implement group tasks (e.g. split reward points among multiple executors).
- Add leaderboard stats to showcase the most active and helpful student executors.
- Support direct peer-to-peer point transfers.

## Phase 3: Mobile Apps
- Develop React Native mobile app wrappers to support native push notifications and background chat updates.
