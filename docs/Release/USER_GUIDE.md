# User Guide

Welcome to LazyOne! Follow this guide to get started.

## 1. Registration and Authentication
- Visit the register page and sign up using your email and password, or use Google Sign-In to authenticate.
- Once registered, you will start with **1500 reward points** by default.

## 2. Managing Tasks
- **Post a Task**: Go to "Add Task", enter a title, description, and the number of reward points you want to offer. Your profile points will be deducted immediately.
- **Browse/Take Tasks**: Visit the home feed to view available tasks posted by others. Click "Take Task" to assign it to yourself.
- **Complete Tasks**: Once you finish a task, mark it complete. You will receive the reward points, and the task status will update.

## 3. Social and Connections
- **Find Friends**: Navigate to "Users" list, search for classmates, and send friend requests with a custom closeness rating.
- **Social Circle**: View your friends arranged in a visual circle on the homepage.
- **Task Chat**: Once a task is accepted, a chat room is created automatically. Use this to text in real-time with the poster/executor about task specifics.
