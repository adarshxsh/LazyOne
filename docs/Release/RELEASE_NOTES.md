# Release Notes - v1.0.0

We are excited to announce the production release of LazyOne!

## Key Features in this Release
- **AWS Deployment**: LazyOne is fully configured and ready for AWS production deployment.
- **WebSocket Real-time Messaging**: Full integration of task conversation channels powered by Django Channels and Redis.
- **Social Graph Visualizations**: High-quality visual representation of friend connections directly on the dashboard.
- **Secure Authentication**: End-to-end sign-in pipelines secured via Firebase authentication.
- **Points Ledger**: Automatic transactions logic for tasks completed and assigned.
