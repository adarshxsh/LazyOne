
## LazyOne 



Problem Statement: 
	Everyone has sort of time, and Lazyness is the key feature of being smart : 
	 there should be system that I can Assign my work to other with some reward 
	 Sometimes going market for just graph paper, pen and other stuff feels irritating so usr can give their small task to one who are doing 

	

Goal : 
	Build a web-app that transfer the task from one user to other and also mentain the state of the task.

Target Users :
College student, Community people 

Time Limit
		10 days 

Budget
    ₹0

Platforms
    Linux, Windows, Mac, Android 

Version
    v1.0

Success Criteria : 
- [ ] Authentication 
- [ ] Task Integrity 
- [ ] Task Completion 
- [ ] Reward Granted 
- [ ] Dispute Solved
